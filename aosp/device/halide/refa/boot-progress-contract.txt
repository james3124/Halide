# device/halide/refa/boot-progress-contract.txt - boot_progress event contract.
# Source: logcat -b events boot_progress_* (ch.03 S27 budget table, ch.04 S5
# container packaging). halide-boot-timeline merges dmesg + journal + these
# events into one CSV (stage,ts_ms,source). tests/boot-timing.sh parses the
# same slice into firmware/ABL/kernel/systemd/container/app-ready columns.
# Budgets: container-to-boot_completed <=60s Phase-3 (S27); dev-loop expects
# host login <=30s then boot_completed=1 within 120s (ch.04 S6).
# Regression rule: any MR adding >500ms to any stage median (5-boot median,
# sacrificial REF-A, same cable/charger/ambient) carries timeline CSV +
# justification or CI boot-budget-check fails the MR.
