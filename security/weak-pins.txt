# weak-pins.txt — weak crypto pins banned in tree (ch.08 §11/§32; CI grep enforced)
# Any reference to the algorithms below in security-relevant code/config fails the build.
# Legacy compat never inherits (kdf-registry.json prohibited list mirrors this file).
banned: md5 (key derivation, transport, signatures)
banned: sha1 (signatures, KDFs; collision-class uses only outside security-relevant paths)
banned: des / 3des
banned: rc4
banned: rsa-1024 and smaller keys
banned: ecdsa-p192 and smaller curves
banned: pbkdf2-hmac-sha1 and pbkdf2-hmac-md5
banned: cbc-mode without ETM for new transports (AEAD preferred)
banned: static IVs / zero IVs
banned: testkey in release artifacts (testkey-never-ships, signer-spec.md)
# Enforcement: scripts/license-check.sh + kdf-registry-check.sh + avb-policy grep.
